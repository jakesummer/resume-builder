# Resume Builder

Live Site: https://resume-builder-3.netlify.app/

## Features

- Full resume builder using [Jake's Resume Template](https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs)
- Preview the resume as you build it
- Download final resume as a PDF with formatting and clickable links
- Fully polished and animated UI
- Fully responsive UI which works on all screen sizes

## Built With

- **Frontend:** React.js, Vite, Javascript
- **Styling:** CSS
- **PDF Generation:** [html-to-image](https://github.com/bubkoo/html-to-image), [jsPDF](https://github.com/parallax/jsPDF)
